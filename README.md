# MomentSnap

Носимый значок с аудио-триггером для ярких воспоминаний.

## Идея

Маленький значок на магнитном креплении носит пользователь. Днём он пишет видео **циклическим буфером** на microSD — только последние минуты. Локальный аудио-фильтр ловит **всплески громкости** (смех, крик, угар) и сохраняет 30-секундные клипы (15 сек до + 15 сек после).

Вечером значок на зарядке → Wi-Fi → синхронизация с домашним сервером. Сервер транскрибирует клипы и через LLM оставляет **только яркое**: шутки, фейлы, эмоции. Мусор отсеивается.

**Цель:** не 8 часов видео, а 5 ярких моментов за день.
