# MomentSnap — финальный план проекта

---

## 1. Что это

Носимый значок на магнитном креплении, который весь день ловит яркие моменты (смех, крик, угар) и вечером превращает их в умный архив. Не пишет всё подряд, не стримит, работает без интернета днём.

**Формула:** железо + подписка на умный архив.
**Цена:** 3000₽ за значок + 200₽/мес.

---

## 2. Три слоя архитектуры

### Слой 1 — Значок (ESP32-CAM)

**Железо:**
- ESP32-CAM со слотом microSD
- Цифровой микрофон INMP441
- Li-Po аккумулятор
- Магнитное крепление

**Что делает днём:**
1. Пишет видео циклическим буфером на microSD (Wi-Fi выключен — экономия батареи).
2. Слушает громкость через INMP441 (RMS по окнам 0.5 сек).
3. При всплеске громкости сохраняет 30-секундный клип (15 сек до + 15 сек после) в отдельную папку.
4. Пишет таймкод + громкость в лог-файл.

**Что НЕ делает:** не транскрибирует, не понимает речь, не решает «оставить/удалить».

### Слой 2 — Сервер (Python, дома или в облаке)

**Что делает вечером, когда значок на зарядке:**
1. Принимает клипы + лог-файл от значка по Wi-Fi.
2. Whisper → транскрипт каждого клипа.
3. LLM → вердикт «оставить/удалить», теги, саммари.
4. Складывает готовый архив.

**Варианты бэкенда:**
- **Локально:** Ollama + Qwen 2.5 7B на RTX 4060 (приватно, бесплатно).
- **Облако:** Whisper API + GPT-4o mini (~50₽/мес на пользователя).
- **Gemini Flash** — бесплатный API Google.

### Слой 3 — Телефон (TypeScript)

**Что делает:**
- Показывает архив готовых клипов.
- Даёт выбрать: «облако» или «локально».
- Пульт управления: запустить синхронизацию, посмотреть вердикты ИИ.

**Что НЕ делает:** не запускает Whisper, не крутит LLM.

---

## 3. Поток данных

```
День:
[Значок] → пишет циклический буфер на SD
         → ловит громкость
         → сохраняет 30-сек клипы + лог

Вечер:
[Значок на зарядке] → включает Wi-Fi
                    → отправляет клипы + лог на сервер

Сервер:
[Python] → Whisper → транскрипт
         → LLM → keep/delete + теги + саммари
         → архив в JSON

Утро:
[Телефон] → показывает 3–5 золотых моментов за день
```

**Трафик:** не 8 часов видео, а 20–50 клипов по 30 сек = ~10–25 МБ. Экономия в 100 раз.

---

## 4. PoC (Proof of Concept) — что делаем сейчас

**Цель:** доказать, что ИИ реально находит «золото» среди мусора. Без покупки железа.

**Что нужно:**
- 20-минутное видео с телефона (прогулка + 3–4 угарных момента).
- Комп с RTX 4060 и 32 ГБ ОЗУ.
- Python + PyCharm.

**Пайплайн:**

```
Видео → FFmpeg → аудио 16 кГц моно
      → RMS-анализ → пики громкости
      → нарезка 30-сек клипов
      → Whisper → транскрипт
      → LLM → keep/delete + теги + саммари
      → results.json
```

**Структура кода:**

```
MomentSnap_PoC/
├── config.py           # все настройки
├── audio_utils.py      # FFmpeg + RMS + нарезка
├── transcriber.py      # Whisper
├── classifier.py       # Ollama / Gemini / OpenAI
├── pipeline.py         # оркестрация
└── main.py             # точка входа
```

**Критерий успеха:** из 20 минут видео → 3–5 клипов, из них 3–4 — реально угарные (совпадение с твоим мнением).

## 7. Бизнес-модель

**Железо:** 3000₽ за значок (по факту себестоимость выше — цену придётся пересмотреть до 5000–7000₽).

**Подписка:** 200₽/мес за умный архив.
- Себестоимость (облако): ~50₽/мес.
- Маржа: ~150₽/мес на пользователя.

**Почему это работает:** облако дёшево, потому что обрабатываем не 8 часов, а 10 минут аудио в день.

---

## 8. Уникальность на рынке РФ

**Аналоги в мире:** Plaud NotePin, Limitless Pendant, Bee.
**В России:** аналогов нет.

**Твоё УТП:**
1. Русский язык из коробки.
2. Локальная обработка — данные не уходят в чужое облако.
3. Аудио-триггер вместо 24/7 записи — приватность и батарея.
4. Дешевле зарубежных аналогов.

---

## 9. Главные риски

| Риск | Что делать |
|---|---|
| Рынок может не существовать | Проверить на 10 людях до покупки железа |
| Юридические проблемы (152-ФЗ) | Локальная обработка + не публиковать чужие лица |
| Себестоимость выше 3000₽ | Пересмотреть цену на этапе 5 |
| ESP32 не тянет | Не тянет Whisper — и не должен. Только запись + громкость |
| Конкуренты из Китая | Русский язык + локальность + поддержка |

## 10. Что делаем прямо сейчас

1. Дописать PoC (модули: `config`, `audio_utils`, `transcriber`, `classifier`, `pipeline`, `main`).
2. Прогнать на 20-мин видео.
3. Посмотреть на `results.json`: сколько клипов keep, насколько вердикты ИИ совпадают с твоим мнением.
4. Показать результат 3–5 одноклассникам.
5. Если они говорят «о, круто, я бы таким пользовался» — заказывать ESP32.

**Не покупать железо, пока PoC не покажет, что ИИ реально находит золото.** Это правило номер один.
